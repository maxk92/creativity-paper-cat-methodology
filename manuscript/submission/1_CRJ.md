# Submission sheet 1: Creativity Research Journal (CRJ)

Publisher: Taylor & Francis / Routledge. Portal: Routledge Submission Portal (the "Go to submission site" link on the
CRJ instructions page). Guidelines checked 2026-10-27 (page updated 14 Sep 2026). No submission or publication fees.

## A. Finish the content (same for every journal)
- [ ] Resolve all `[FILL IN …]` (32) and `[AUTHOR TO CONFIRM …]` (29) markers, then remove the highlight filter
      (`mark-highlight.lua`) and the `.mark` spans. Delete the author-notes HTML comment block.
- [ ] Authors: full names, affiliations, ORCIDs, corresponding author email. Get approval from all co-authors.
- [ ] Ethics: committee name, reference number, informed-consent procedure (FI-1).
- [ ] Software versions (FI-6) and a data/code availability statement (FI-15). Deposit data and code in a repository with a DOI if you share them.
- [ ] Re-render and check the reference list against the bib fixes (`bib_fixes_todo.md`).

## B. CRJ-specific manuscript changes
- [ ] **Abstract: unstructured, 200 words or fewer** (now 252).
- [ ] **Remove keywords** (CRJ says "Do not include keywords").
- [ ] **No first person, and no "the authors"**: rewrite every "we"/"our" (for example "This study…", "The models were fitted…").
- [ ] **Past tense** for all results and for previous research ("Kaufman et al. (2008) reported…").
- [ ] "Data" is plural; serial comma; American spelling; double quotation marks.
- [ ] Report exact *p* values (for example *p* = .03; "*p* < .001" is fine below .001) and effect sizes.
- [ ] Use footnotes sparingly; indent all paragraphs.
- [ ] State the word count (no limit applies).

## C. Required statements (at the end of the main text, before the references)
- [ ] Funding statement, or "No funding was obtained".
- [ ] Disclosure statement (competing interests, or "The authors report there are no competing interests to declare").
- [ ] **Declaration of generative-AI use** (how AI was used in the research and in preparing the manuscript).
- [ ] Data availability statement (repository and DOI, or reasons for not sharing).
- [ ] Acknowledgments (raters, if appropriate).
- [ ] CRediT roles (entered in the portal).

## D. Layout and files
- [ ] Order: title page, abstract, main text, acknowledgments, declaration of interest, references, appendices,
      **tables (one per page, with captions)**, figures, **figure captions as a list**.
- [ ] Double-spaced, 1-inch margins, 12-pt Times New Roman (or similar), consecutive page numbers.
- [ ] **Submission date (month, day, year) on the title page.**
- [ ] **Two manuscript versions**: "Manuscript – with author details" and "Manuscript – anonymous" (remove names,
      affiliations, acknowledgments, self-identifying references and links, and file metadata).
- [ ] Figures as **separate files** (TIFF/EPS/JPEG; 300 dpi colour, 600 dpi greyscale, 1200 dpi line art). Optional alt text.
- [ ] Supplementary material as a separate file (published via Figshare).
- [ ] Format route, choose one:
  - **Word**: render Quarto to .docx; check that the tables are editable Word tables and the equations are editable.
  - **LaTeX**: render to PDF and upload it as the manuscript file, and upload the `.tex` and assets as **one zip** labelled "LaTeX Source Files". (The T&F LaTeX template is optional.)

## E. Cover letter
- [ ] Explain why the paper suits CRJ (CAT reliability and rater effects; JRT).
- [ ] **State the preferred review model**: double-anonymous (default) or single-anonymous.
- [ ] Confirm the work is original and not under review elsewhere; mention any preprints or conference presentations.

## F. In the portal
- [ ] Enter metadata (title, abstract, authors with ORCID, CRediT roles, funding).
- [ ] Answer the data-set question (DOI or link, or "no").
- [ ] Upload: cover letter, both manuscript versions, figures, supplement, and the LaTeX zip if you use the LaTeX route.
- [ ] Check the generated PDF proof, then submit.
