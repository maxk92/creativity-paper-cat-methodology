# Submission sheet 2: The Journal of Creative Behavior (JCB)

Publisher: Wiley. Portal: the "Submit an article" link on the JCB author-guidelines page
(onlinelibrary.wiley.com/page/journal/21626057/homepage/forauthors.html). Guidelines checked 2026-10-27.
**Free Format submission**: any editable layout, and references in any consistent style.

## A. Finish the content (same for every journal)
- [ ] Resolve all `[FILL IN …]` and `[AUTHOR TO CONFIRM …]` markers; remove the highlight filter, the `.mark` spans and the author-notes comment.
- [ ] Authors, affiliations, ORCIDs, corresponding author; get approval from all co-authors.
- [ ] Ethics committee, reference number and consent procedure (FI-1); software versions (FI-6).
- [ ] Re-render and check the reference list.
- [ ] If you are coming from CRJ: CRJ-specific changes (third person, no keywords) can stay or be reverted. JCB accepts either.

## B. Open-science requirement (required since 1 Jan 2026; without it the paper is returned before review)
- [ ] Deposit the **data** (rating data with pseudonymised rater IDs) and the **analysis scripts** (R pipeline in
      `data-analysis/creativity-ratings-psychometrics/R/`) on a reliable platform (OSF, Zenodo) **with a reuse licence**
      (for example CC BY 4.0 for data, MIT for code).
- [ ] Add a codebook and check that the scripts run from a clean checkout (strongly encouraged).
- [ ] Put the links in the manuscript. Use an anonymised view-only link if the review is masked. If some data cannot be shared,
      **state the legal or ethical reason in the manuscript**.

## C. JCB-specific manuscript checks
- [ ] Article type "article": **6,000–12,000 words including references** (above 10,000 is discouraged). Count after rendering.
- [ ] All sections present: abstract, introduction, method, results, discussion; figures and tables with legends.
- [ ] The paper is "adequately situated in the creativity studies literature" (CAT literature in the introduction is already there).
- [ ] Proofread carefully, since the editor screens for adherence and fit.

## D. Required statements
- [ ] Data availability statement.
- [ ] Funding statement.
- [ ] Ethics approval statement (and participant consent, which covers the raters).
- [ ] Conflict of interest statement.
- [ ] **Detailed AI-use disclosure** (Methods or Acknowledgements): tool name and version, dates of use, purpose,
      the sections where it was used, and how outputs were checked and revised. Authors take full responsibility.

## E. Files
- [ ] Manuscript: one editable file (Quarto to .docx) with figures and tables embedded, or as separate files.
      Figures at the highest resolution available.
- [ ] Supporting information (supplement) as a separate file.
- [ ] Title page with author details, plus an anonymised manuscript if the system asks for one.

## F. Cover letter
- [ ] **State the submission type: "Article".**
- [ ] Explain the fit and contribution (reliability of CAT scores in incomplete designs; rater differences; JRT in sport).
- [ ] Confirm originality and that the paper is not under review elsewhere. Note any text overlap with earlier work (text recycling).

## G. In the portal
- [ ] Enter metadata and upload the files; answer the ethics and data questions; submit.
